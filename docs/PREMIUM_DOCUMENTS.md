## Package A — protected portraits and snapshots

`Portrait` retains each normalized review record with a random UUID, consent audit, uploader, explicit pending/approved/rejected state and administrative decision evidence. Only JPEG/PNG single-frame content up to 3 MiB and 16 million pixels is accepted. Integrity is verified, EXIF orientation corrected, centered 4:5 crop previewed, and metadata stripped into a 600 × 750 JPEG. No facial recognition, matching or automatic identity decision. Original input is discarded.

Normalized JPEGs are Fernet-encrypted in the existing protected database using the existing data-key service. There is no media file or public/predictable media URL. Random UUID retrieval still enforces ownership/authorized guardian or live administrative MFA/delegation. Images and private pages are no-store. Review commands additionally require recent password/factor verification and reasoned audit. Upload does not grant membership, accreditation, office or admin rights.

Issuance binds the latest approved portrait to applicable card records. The FK is PROTECT and the snapshot is not rebound when a new photo is uploaded or approved. Existing issued cards with no portrait stay unbound; formal audited reissuance through existing commands is required to adopt one. A photo-capable final PDF must fail closed as pending-photo when this snapshot is absent. The legacy HTML service remains backward compatible in this package; PDF pending-photo enforcement belongs to package B.

Routes: member/guardian `/members/portrait/`, MFA-protected `/operations/portraits/`, authorized `/private-portraits/<uuid>/`. Every state mutation is POST/CSRF with scoped choices and existing replay/transaction boundaries. Audit never includes image data or original filenames. Existing legal readiness (retention, rights handling, notices, hosting/CNDP review) remains a prerequisite to real-data deployment; no statutory conclusion or retention period is invented.

## Package B — approved design and protected PDFs

Existing categories only: general, affiliate/associate, advanced, accredited, founder, honorary; institutional president/vice_president/founder. All eight supported design categories have coherent front/back layouts with the issuance portrait. Founder/permanent and office dates follow existing records. Professional and existing accreditation certificates use the approved A4 composition. Participation has no approved issuance/eligibility contract; it is deliberately rejected rather than inferred from a template.

WeasyPrint/Pango/HarfBuzz renders embedded SIL OFL font outlines, shaped Arabic, French accents and Latin text. Dynamic text is escaped. A closed resource fetcher accepts only the fixed in-memory logo, decoration, font, portrait and vector QR resource map; no external HTTP/file/data retrieval. Portraits are normalized 600 × 750 JPEGs; card backgrounds are 468.54 effective DPI. The original emblem remains unchanged. Font licensing/provenance and vector reconstruction parameters are in governance/document_assets/README.md. Output is RGB; no PDF/X or CMYK certification is claimed. Optional 3 mm bleed adds explicit MediaBox/BleedBox/TrimBox while keeping the approved trim dimensions. Holder names shrink within bounded readable sizes and fail closed for layout review if they cannot fit; identity is never truncated.

PDFArtifact uses an additive migration, PROTECT relationship, encrypted payload, digest, template version, dimensions/language metadata, and a unique document/language constraint. Generation locks the existing document and lifecycle origin (linked membership before accreditation), rechecks revocation/suspension/expiry, and reuses any artifact already produced. New profile/portrait/template changes do not rewrite an issued PDF; existing formal replacement creates a separate identity and history. Existing outbox rendering prepares AR/FR/EN PDFs, with explicit pending_photo/pending_layout/inactive_document feedback and backward-compatible encrypted HTML. Inactive PDF jobs remain retryable through the existing bounded worker; reactivation can complete all languages without overwriting completed HTML or PDF artifacts. Missing issuance portrait requires formal reissuance; no placeholder silently substitutes for the holder.

Routes: owned/authorized /my-documents/<id>/preview/ for ephemeral marked previews; /my-documents/<id>/pdf/ for existing artifacts; /my-documents/<id>/prepare/ accepts POST/CSRF only to generate. Member/guardian ownership or existing live administrative authorization/recent MFA is enforced. Access and generation are audited and no-store. Generation, preview and download share document/origin locks and retain them through audit/response construction; administrative authority is acquired first to match existing command order. Revoked, suspended and expired documents fail closed; public QR verification remains unchanged and never receives portraits or PDF payloads. Every synthetic output visibly says SPECIMEN / نموذج تجريبي. Production configuration remains blocked.
