# ADR 039 — Public tools catalog and private contact requests

Date: 2026-10-24. Authority: owner requests a tools page with image/text/link, detail and contact-request form. Status: prepared; reviewed CI/deployment evidence remains separate.

## Decision

Add Tools & Resources (أدوات وموارد / Outils et ressources), linked from the existing public and member navigation. Public catalog/detail/image GETs expose published editorial resources only, with pagination, plain escaped text, an optional HTTPS link and an optional normalized JPEG/PNG stored in PostgreSQL. No filesystem uploads, private portrait reuse, remote fetch or provider translation. Arabic copy is required; optional manual FR/EN fields fall back to Arabic. Start with an honest empty catalog; no invented or synthetic production resources.

A per-tool form accepts full name, validated contact phone and email. It explains contact-only use, private handling and no guaranteed availability/delivery. Existing versioned privacy acknowledgements are recorded with the distinct tool.request purpose when the notice is active. No account or membership approval is created, and no clinical/free-text applicant field, payment, automatic email, fulfillment or member identity matching is added. A signed four-hour token binds the tool and a random nonce; identical replays do not duplicate requests or privacy evidence, changed-input replays fail. CSRF, shared-ingress request budgets and existing APPLICATIONS workflow guards apply. Tool publication is locked against request creation; unpublishing hides editorial routes and blocks new requests without deleting old ones.

The primary administrator's existing MFA/epoch check protects all catalog/request operations; no extra delegated access is inferred. The admin menu opens tools and newest paginated requests, with filters and request states New / Contacted / Closed, private notes and visible phone/email for manual follow-up. Commands reauthorize under the existing Authority lock and retain idempotency/audit. Admin image previews stay private, including for unpublished tools. Public GETs never receive applicant names, contacts, notes or request counts. No request is sent to Gmail, Gemini or another external provider. The dashboard is the delivery channel to administration; existing automatic email remains disabled.

Migration0017 adds MemberTool and ToolRequest. No existing fees, membership policies, issued assets or private records are rewritten. Verify synthetic create/publish/image/unpublish/request/replay/consent/CSRF/throttle/admin authorization and review; run AR/FR/EN responsive browser submission plus PostgreSQL/recovery/container CI and code review. Hosted acceptance uses anonymous reads only, never synthetic production applicants. Existing ANTHEC resources only; no Tighri action or new costs.
