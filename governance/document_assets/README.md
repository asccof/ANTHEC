# Owner-approved visual assets, v4

Gold and president PNG backgrounds and the approved logo are copied unchanged from the synthetic approved v4 proofs. Effective background resolution is at least 468 DPI at CR80; the logo exceeds 1000 DPI at its largest 19 mm placement. No source association attachment or original reference sheet is included.

`certificate.svg` reconstructs the approved generated certificate background as vector Bézier paths using VTracer 0.6.15 (MIT; offline build tool, not a runtime dependency): color/stacked/spline; filter_speckle=16, color_precision=5, layer_difference=24, corner_threshold=60, length_threshold=4, max_iterations=10, splice_threshold=45, path_precision=3. SVG contains no text, fonts, raster image, external resource or seal/signature. This removes a low-resolution raster from the PDF; it does not invent detail absent from the approved source or establish physical print quality. Physical inspection remains required.

Font sources: Google Fonts ofl/ibmplexsansarabic, ofl/notonaskharabic, ofl/cormorantgaramond. SIL OFL 1.1 licenses included. Static Regular/SemiBold faces are losslessly WOFF2-packaged for local embedding. The repackaged IBM faces' primary family names are renamed ANTHEC Arabic UI to respect the reserved name Plex; shapes are unchanged. CSS aliases do not change the embedded outlines. No paid fonts or external font fetching.

The runtime reads only this fixed asset directory and request-local normalized portrait/QR bytes through a closed fetcher map. It cannot fetch HTTP/FTP/file/data URLs supplied by content. Category backgrounds beyond the three approved proofs use original restrained vector guilloche/ribbons and the approved category palette, with the same front/back information hierarchy. They do not add membership categories or legal claims.
